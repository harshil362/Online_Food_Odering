# 🍔 FoodieHub – Online Food Ordering System

FoodieHub is an online food ordering website made using ASP.NET, HTML, CSS, Bootstrap, and JavaScript.

## Features

- Home Page
- Food Menu
- Search and Category Filter
- Add to Cart
- Checkout
- Payment Options
- Login & Registration
- User Account
- Order Confirmation
- Contact & About Page

## Technology Used

- ASP.NET Web Forms
- C#
- HTML
- CSS
- Bootstrap
- JavaScript

## Purpose

This project is created for learning and educational purposes.
